# Repository Rules

## Active GitHub Repository
- **Remote Repository URL**: `https://github.com/Sai-KT/IIIT-Aquamanage.git`

## Git Auto-Commit Directive
- Automatically stage, commit, and push changes to Git (`git add . && git commit -m "..." && git push origin <current-branch>`) to `https://github.com/Sai-KT/IIIT-Aquamanage` whenever ANY user-requested code change, bug fix, feature, refactor, or file update is completed.
- Never ask the user for confirmation before committing and pushing; execute this automatically on completion of every change or feature.
